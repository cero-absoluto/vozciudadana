# Voice Protest is a hash-routed single-page app (voiceprotest.org/#/auth,
# /#/create, etc.) — everything after the # is never sent to the server, so
# a Disallow rule per route here would have no effect (crawlers only ever
# see "/"). Internal routes (auth, verify, create, group management,
# invite links) are excluded from indexing instead via a `<meta
# name="robots" content="noindex">` tag injected at runtime based on the
# active route — see src/router/index.js.
#
# Two sitemaps, two different jobs (Discoverability Phase 2, 16 July 2026):
# - sitemap.xml (this domain, static): the fixed pages — home and
#   quienes-somos.html in its 4 languages. Hand-maintained, changes rarely.
# - reports.voiceprotest.org/sitemap.xml (generated by Railway on every
#   request, straight from Supabase): every convocatoria and public report,
#   always current — a convocatoria created five minutes ago is already in
#   it. See apps/api/src/routes/reports.js.
User-agent: *
Allow: /

Sitemap: https://voiceprotest.org/sitemap.xml
Sitemap: https://reports.voiceprotest.org/sitemap.xml
