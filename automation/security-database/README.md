# S14 synthetic database rehearsal

`native/launch.mjs` starts only its own temporary PostgreSQL17.6 cluster on loopback127.0.0.1:55451, authenticates with a random local password, checks its cluster name, runs `native/run.mjs`, stops it and removes its own temporary directory. It never contacts Supabase, a provider or production. Install the pinned native test dependencies with `npm ci --ignore-scripts` in native/ as an ordinary user, then run `node native/launch.mjs` from this directory. Existing reviewed local packages can instead be supplied with CENSUS_NATIVE_BIN_MODULE and CENSUS_NATIVE_PG_MODULE file URLs. In the supplied single-UID namespace only, CENSUS_ALLOW_NAMESPACE_UID_ADAPTER=1 enables the reused OS-identity adapter; it changes no SQL role/lock behavior.

metadata.json contains schema, constraints, RLS/policy and function ACL metadata only, read in production with BEGIN READ ONLY/ROLLBACK on2026-10-28. It contains no rows, keys or logs. Two relevant live trigger bodies and definitions are installed with synthetic data; other legacy functions are placeholders for signature/ACL tests, not implementation certification. The live RPC SQL and relevant trigger metadata were read separately; the live erase_anonymized_identity trigger only clears fields when anonymized_at is nonnull, and the new RPC rejects that state before updating. The census trigger watches columns the RPC does not update. No live schema or user dump is restored here.

The SQL proposals are docs/proposals/database-minimum-privileges.sql and gps-reinforcement-atomic.sql, applied in that order in the synthetic cluster. Native tests cover actual PostgreSQL grants/column privileges/RLS, new RPC semantics, parallel clients, real row lock waits, closure/expiry after waits, transaction rollback and lock timeout. API tests mock Nominatim and Supabase transport separately. Actual PostgREST schema reload/column errors, production load, all legacy trigger side effects/retention beyond the inspected functions, cron, backup completeness and real client geolocation are not certified by these fixtures.

The final fixture uses ICU/en-US default collation, non-superuser ownership, foreign grantors, inherited default grants, a private sequence, and a read-only drift check. FOR SHARE is retained deliberately: a weaker-lock negative control demonstrates the stale mutable deadline failure. No schedule or production CI secret is configured.
