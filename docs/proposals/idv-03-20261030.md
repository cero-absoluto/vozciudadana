# IDV-03 — validar evidencia del geocodificador

30/10/2026. Candidato para revisión; no publicado en producción.

Una respuesta HTTP fallida o JSON de error ya no se convierte en GPS confirmado.
Las rutas de admisión y refuerzo comparten un parser: HTTP correcto, objeto de
respuesta y dirección, código de país de dos letras y localidad o región textual
válida. Los campos de lugar están limitados a 512 caracteres; un OSM inválido se
omite. Esto valida una respuesta geográfica mínima, no presencia física certificada.

En admisión, el fallo conserva la degradación existente a IP o ausencia de señal.
En refuerzo, devuelve 503 sin invocar la RPC que consume el token; un reintento
posterior válido puede completarse. Se conserva la protección frente a concurrencia,
la política de riesgo y los códigos de rechazo de base de datos.

Validación local: 667 pruebas generales correctas, dos omitidas; 37 pruebas dirigidas
correctas. Incluyen errores HTTP aunque el cuerpo parezca válido, JSON inválido,
respuesta de error, país ausente, datos mal tipados, fallback IP, ausencia de consumo
del token y reintento. Compilación web correcta; CSP correcta en cinco HTML.

Sin cambios SQL, proveedores reales, OTP real, datos históricos ni despliegues.
