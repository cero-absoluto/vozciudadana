# IDV-04 — separar procedencia geográfica

30/10/2026. Candidato parcial de API; no desplegado. IDV-04 permanece abierto.

El país aportado por GPS ya no cuenta como corroboración IP. La resolución marca
explícitamente `ip_country_confirmed` solo tras una respuesta IP HTTP correcta,
sin error y con país de dos letras. La API calcula las señales a partir de esa
procedencia. GPS válido no genera una segunda consulta IP innecesaria.

Índices existentes conservados según señales efectivas: identificación sola 75,
identificación e IP 85, identificación y GPS 92; dos procedencias independientes
95 solo si se obtuvieron ambas. Son índices internos, no probabilidades calibradas.
La ruta actual elige GPS o fallback IP, por lo que no obtiene ambas a la vez.
No se recalculan registros anteriores.

Validación: 673 pruebas generales correctas, dos omitidas; 20 pruebas de rutas y
servicio con proveedores simulados, incluida persistencia GPS/IP/sin geografía.

Pendiente antes de cerrar IDV-04: función institucional viva
`verify_institutional_challenge_and_create_adhesion`, MD5
`51bc6c14aa8d5127a7467681b3bd844d`, asigna 90 y email_otp,ip fijos. La lectura
fue solo de definición, sin datos personales. Hay que corregirla bajo pruebas
PostgreSQL sintéticas, preservando fundador/OTP/transacción y ACL. También deben
revisarse las afirmaciones públicas del índice junto a IDV-07/11/12.

Este candidato no cambia funciones SQL, políticas de admisión ni automatizaciones.
La revisión externa de este candidato sigue pendiente.
